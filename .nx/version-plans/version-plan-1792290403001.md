Add `AndesColorPicker`: a swatch trigger that opens a panel with a saturation/brightness area, hue and opacity sliders, HEX/RGB/HSB/HSL/OKLCH fields, labelled preset groups and an eyedropper where the browser has one. It reads and writes colour text or an `AndesColor` (parsing, formatting and conversions are plain TypeScript, no dependencies), works with Angular forms, and reports `colorChange`, `colorChangeComplete`, `clear` and `openChange`.

- `trigger="hover"` opens the panel after a short rest on the trigger and closes it once the pointer has left both, across a bridged gap; click, tap and the keyboard (Enter, Space, ArrowDown) still open it and Escape returns focus. `arrow` draws an arrow pointing at the trigger on either side, in both directions.
- `mode="gradient"` edits a linear gradient: a bar of draggable, keyboard-operable colour stops (`role="slider"`), add and remove, an angle dial and field, gradient presets. The value is CSS `linear-gradient()` text or an `AndesGradientValue`, read and written by the new `AndesGradient`; change events gain a `gradient` part.
- `AndesColorPickerPanel` renders the same panel inline, with the same inputs, events and forms support; the picker's popup is that panel.
- Presets can be non-collapsible (`collapsible: false`) and hold gradients; `recentColors` keeps a "Recent" group (`recentColorsMax`, `recentColorsStorageKey`, two-way `recent`).
- `confirm` stages edits behind Apply / Cancel (`applied`, `cancelled`); `slot="panel-header"` / `slot="panel-footer"` content is projected into the panel.
- A copy button (`showCopy`, `copied`) with a polite "Copied" announcement; `contrastWith` shows the WCAG contrast ratio with AA / AAA badges; `name` renders a hidden input for native forms; `readOnly` shows and copies the colour without letting it change.
- The panel has no native select, text or number control, only the library's own components: the format switch is `andes-select` (sized to the chosen format, its list opens above the popup and inside an inline panel, Escape closes only the list and focus returns to its trigger), the hex field is `andes-input` with a `#` prefix, every number field (channels, opacity, gradient angle, a new stop position field) is `andes-input-number` with `%` / `°` suffixes, and copy, add / remove stop, eyedropper, Cancel and Apply are `andes-button`. The compact number fields fit their content (about 60px at the small size) instead of stretching, and the channel boxes share one row of equal columns. Typing a number beyond its range is clamped when the field is left rather than on every keystroke.
