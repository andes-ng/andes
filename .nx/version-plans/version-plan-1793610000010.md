`AndesEmpty` now matches Ant Design's Empty: the illustrations and sizes follow Ant's (a 100px picture, 40px for `simple`, 35px when `small`), `classNames` and `styles` reach each part (`root`, `image`, `heading`, `description`, `footer`) as objects or as functions of the resolved state, and a new `heading` input adds a title line. `provideAndesEmpty()` and the `[andesEmptyProvider]` directive set the image, message, per-preset texts (`ANDES_EMPTY_TEXTS_ES` for Spanish) and part styling of every empty state below them, the counterpart of Ant's `ConfigProvider`. `AndesSelect`'s `notFoundContent` now defaults to an `andes-empty` (the `select` preset, which follows that provider) instead of the plain text `No data`; text, a template and `null` work as before.
