The alert dialog gains confirmation guards for destructive actions, all optional and composable: `andes-alert-dialog-confirm-phrase` (type a name or word before the action unlocks, with case, whitespace and paste options), `andes-alert-dialog-acknowledge` (a checkbox that has to be ticked), `andes-alert-dialog-countdown` (a pause with a progress bar), and `[holdDuration]` on `andesAlertDialogAction` (press and hold with Space, Enter, pointer or touch, with a cancellable alternative for screen readers).

A gated action stays focusable with `aria-disabled`, is described by what is missing, and shakes and announces it when pressed early. `[confirm]` on the action takes an asynchronous handler: the dialog stays open with the action busy, Cancel and Escape are unavailable while it runs, and a failure shows in `andes-alert-dialog-error` so the user can retry. `[armDelay]` ignores the action for a moment after opening, `tone` and `andes-alert-dialog-icon` draw the tone icon, `initialFocus` picks the control focused on open, `andesAlertDialogSecondary` adds a third answer at the start of the footer, and `andes-alert-dialog-impact` lists what the action will affect.
