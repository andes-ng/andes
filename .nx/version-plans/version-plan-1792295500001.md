Add `AndesCascader`: a select-like field that opens a panel with one column of options per level, for picking a path through a tree. It supports multiple selection with tags and checkboxes, `changeOnSelect`, click or hover expansion, options loaded on demand with `loadData`, search across every path with highlighted matches, custom display and field names, and tree keyboard navigation (arrows to move, open and close columns, Enter to pick) with a combobox that keeps focus. The pointer highlights an option only after it moves, so a panel opening under a resting pointer shows no highlight, and the cursor stays visible in the dark theme. It also offers `[(open)]` and `defaultOpen`, `name`, `required`, `autoFocus`, `focused` and `blurred`, a two-way `searchValue` with `autoClearSearchValue`, `optionTemplate` applied to search results, `panelHeader`, `panelFooter` and `panelScroll`, and the `tagTemplate`, `prefix`, `suffixIcon`, `clearIcon`, `removeIcon` and `loadingIcon` templates. With `multiple`, an option's check box pops, draws its tick and rings softly when a click changes it, with the checkbox's own motion. `maxTagCount="responsive"` keeps the tags on one row, the `+ N ...` tag opens a popover that lists and removes the hidden ones (`maxTagPopover`), `maxTagPlaceholder` rewords it and `maxTagTextLength` cuts long tags short. `maxCount` caps how many paths a multiple cascader holds. The clear button cross-fades with the chevron or spinner instead of replacing it. A tag the user adds grows in, a column that opens slides in, and the weight of a picked path eases. The empty panel draws a muted tray above its text. Without search, typing jumps to the matching option; a loading option is `aria-busy`, and a live region announces the paths the user adds or removes. An `expandIcon` template replaces the arrow of an option that opens a column. `showSearch.render` renders the search results, and a `searchIcon` template stands in for the chevron while the search is open.
