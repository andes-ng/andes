`AndesTransfer` now shows an empty list as an `andes-empty` (the `select` preset: the simple picture at Ant Design's small size, 35px) instead of an icon and plain text, so it follows `provideAndesEmpty()` and `[andesEmptyProvider]`. `emptyText` accepts text or a template (given the same context as `empty`) and is unset by default, which shows the provider's message or "No data"; `noMatchText` is the message of a search with no match, in the same `andes-empty`. The `empty` template still replaces the whole state.
