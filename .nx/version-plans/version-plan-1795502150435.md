Fix an overlay whose content is projected from the consumer's view (a composed Popover, a Dropdown Menu, a Dropdown Button) losing track of that content after its first close: `contentElement()` stayed unset on every later opening, because the content directive registers only when the consumer's view is created. A composed Popover therefore stopped measuring its arrow and motion origin, following its content's size and flipping on those openings, and a sub menu read its text direction from nothing. The overlay now publishes the registered content again each time a pane takes it.
