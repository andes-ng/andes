Alert: slimmer and softer. A one-line alert is a 40px strip (10px by 12px padding, a 16px icon, 14px/20px text); an alert with a title and a description is 66px (12px by 16px padding, a 20px icon, a medium 14px/20px title over a softer 13px/20px description 2px apart), down from 97px and more. The close button is a 20px ghost button with a 14px cross. The severity colors now follow the theme's status tokens, and every glyph, text and close-button color clears WCAG AA on the light and the dark theme (the warning glyph takes the darker amber). New: a `neutral` severity, a `solid` variant, a `size` input (`sm` is a 30px strip), a two-way `open` model to show or hide the alert with the same collapse as the close button, a `duration` that closes the alert by itself and holds while it is hovered or focused, and a `reason` (`button` or `timeout`) on the `closing` event, whose `originalEvent` is now null on a timeout. The stories are grouped by topic: basics, content, actions, dismissal, banners, customisation, accessibility and compositions.
