AndesPagination: new `layout` input (`default`, `compact` for previous / "Page 2 of 10" / next, and `table` for the data-table footer with "Rows per page", the item range and first / previous / next / last buttons), `variant` (`default`, `outline`, `ghost`, `filled`) and `shape` (`default`, `pill`), `showFirstLast`, `prevText` / `nextText` with `showNavIcons`, `hasNextPage` for a cursor-style control with no known total, `loading`, `linkFor` to draw the items as links, `classNames` and `styles` for each part (objects or functions of the control's state), `jumperIcon`, `defaultCurrent` / `defaultPageSize`, and localisable `firstLabel`, `lastLabel`, `rowsPerPageLabel`, `statusLabel` and `rangeLabel`.

AndesPagination now draws every item (pages, previous, next, first, last and the jump links) with the library button, which is a link when `linkFor` gives the page an address, and its quick jumper and simple-mode page field with the library input; a new `color` input sets the colour that marks the current page.

AndesButton: new `aria-current` input, written on the real button or link. AndesInput: new `inputMode` input, written on the native field.

AndesPagination now announces the page and the item range after each change, moves focus along its items with the arrow keys, Home and End, marks a quick jumper that holds text that is not a page number as invalid, and uses the library select for the page-size changer.

AndesPagination items are 4px, 6px and 8px apart (small, default, large) with an 8px radius, and the page-size and jump-to fields sit 24px after the pages.

The Pagination stories are now grouped by topic (overview, sizes and variants, navigation, page size, total and ranges, simple and compact, state and control, customisation, accessibility, compositions), one story per example.
