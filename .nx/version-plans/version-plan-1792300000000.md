Add AndesTree, a tree view with expand and collapse, single or multiple selection, cascading checkboxes, lazy loading, filtering with match highlighting, connector lines, drag-and-drop reordering with a keyboard alternative, virtual scrolling and the WAI-ARIA treeview keyboard model, plus pure helpers (`andesFlattenTree`, `andesConductCheck`, `andesMoveTreeNode`, `andesFilterTree`) for working with tree data. A check box pops, draws its tick and rings softly when a click changes it, with the checkbox's own motion. `andesTreeFromFlat` builds the nodes from flat data that names each item's parent (`id` / `pId`).
